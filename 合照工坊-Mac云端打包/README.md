# 合照工坊 Mac 云端打包

仅包含分发源码，不含个人图片、素材、草稿或模型权重。权重在构建时从公开源下载并校验。

1. 将本文件夹内容（包括隐藏的 `.github` 目录）放入自己的私有 GitHub 仓库。
2. 在账户 Billing 设置核对剩余 Actions 额度；若不希望付费，设置停止超额使用的预算。工作流本身无法保证账户不会产生费用。
3. 打开 Actions → Build Mac app → Run workflow，先选 arm64。朋友用 Intel 时再运行 intel，避免重复消耗额度。
4. 单次运行超时 20 分钟，构建产物保留 1 天；完成后及时下载 Artifacts。无推送触发、无定时任务。
5. 下载产物内的 PhotoStudio-Mac-*.zip，发给朋友；无需将源代码包发给使用者。

构建同时验证冻结应用两套模型与本机 HTTP 启动。首次云端构建尚待运行，不应将本源码包视为已生成的 .app。
